# dqwv2 — 無課金ウォーカーの手引き

無課金でドラクエウォークを続けるプレイヤー向けの支援サイト。日課チェックリスト、
イベント情報ボード、オートバトル安定重視のパーティ編成・装備ガイドをまとめています。

デプロイ先: https://syunnjack.github.io/dqwv2/

## セットアップ

```bash
npm install
npm run dev
```

## 主なコマンド

- `npm run dev`: 開発サーバー起動
- `npm run build`: 本番ビルド
- `npm run preview`: ビルド結果のプレビュー
- `npm run lint`: oxlintによる静的解析

## データについて

日課・イベント情報・パーティ編成ガイドは、いずれも自動取得ではなく手動入力です。
ゲームの実際の仕様・確率・日程は公式情報で確認のうえ、自分の言葉で記録してください。
データはブラウザのlocalStorageに保存されます(サーバーには送信されません)。

## 収益導線を有効にする

### アフィリエイトリンク(歩行関連グッズ)

「歩き続けるためのおすすめグッズ」セクションの各カードにある入力欄に、実際の商品ページの
アフィリエイトURLを貼り付けてください。空欄の間はリンクが無効表示になります。

### Google AdSense

1. AdSenseで発行された `<script>` タグを `index.html` の `<head>` に追加する。
2. `src/App.jsx` の `.ad-slot` の中身を、AdSenseが発行する `<ins class="adsbygoogle">` タグに
   置き換える。
